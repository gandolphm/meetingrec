# Whisper name corrections — yours

Your own name corrections for team notes. The skill copied this file from
`names.local.example.md` the first time it ran. Git ignores it, so nothing here is ever
committed, and updating the repo never overwrites it. The skill reads it together with `names.shared.md`; if both list the same name, this file wins.

Add customers, partners, guests, advisors and jargon as they come up, so future write-ups
stay consistent: e.g. `Kalibra / Calibra` → **Collibra**. When the skill catches a name
Whisper got wrong, it offers to add a row here. You can also add rows yourself.

The `meeting-notes` skill in `scribe/` keeps its own tables. Names you need in both kinds of
notes go in both.
