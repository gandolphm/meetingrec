# Shared settings — team notes

Names and rules for everyone using one copy of meetingrec. The skill reads this file on
every run together with your own `personal.md`; where they disagree, yours wins.

**This file is empty on purpose, and stays empty in the public repo.** It exists for teams
that fork meetingrec: the fork's maintainer adds what everyone on the team needs (colleagues,
customers, the company's jargon, how the company wants notes written) and commits it, and
each member gets it with their next update. Git tracks this file, so anything written here
is published with the repo.

**Your own names and rules never go here.** They go in `personal.md` next to this file,
which git ignores. The skill creates it the first time it runs and adds to it as you go.

## Names

Whisper reliably mis-transcribes proper nouns. The skill feeds these spellings into the
Whisper prompt before transcribing, and corrects any that still come through wrong.
